*QGroundControl*(QGC)是为无人机设计的高度直观和强大的地面控制站(GCS)。无论您是首次飞行还是经验丰富的专业人士，QGC都能为飞行控制和任务规划提供无缝的用户体验，使其成为任何*MAVLink型无人机*.

---

###🌟*为什么选择QGroundControl？*

- *🚀 易用性*：一个初学者友好的界面，设计流畅的操作，而不牺牲先进的功能为专业人士。
- *✈️ 综合飞行控制*：全面飞行控制和任务管理*PX4*和*ArduPilot*动力无人机。
- *🛠️ 任务规划*：使用简单的拖放界面，轻松规划复杂任务。

🔍 要深入了解QGC的使用，请查看[用户手册](https://docs.qgroundcontrol.com/en/)-尽管，由于QGC的直观UI，您可能甚至不需要它！


---

###🚁*主要功能*

-🕹️*完全飞行控制*：支持所有*MAVLink无人机*.
-⚙️*车辆设置*：定制的配置*PX4*和*ArduPilot*平台。
-🔧*完全开源*：定制和扩展软件以满足您的需求。

🎯 查看我们的最新更新[新功能和发行说明](https://github.com/mavlink/qgroundcontrol/blob/master/ChangeLog.md).
